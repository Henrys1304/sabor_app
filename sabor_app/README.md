# SaborApp

App de receitas feito em Flutter para a disciplina de [nome da disciplina], UNIVÉRTIX.

## Funcionalidades
- Lista de receitas com busca por nome
- Alternância entre lista e grade
- Resumo rápido ao pressionar e segurar um card
- Tela de detalhes com ingredientes e modo de preparo
- Botão de favoritar com retorno para a tela inicial

## Como rodar
flutter pub get
flutter run
